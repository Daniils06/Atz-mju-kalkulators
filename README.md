# Studentu atzīmju kalkulators

## Apraksts
Šī Java programma aprēķina studentu gala vērtējumus, izmantojot kritērijus un to svarus. Lietotājs ievada vārdus, kritērijus, svarus un vērtējumus, un programma datus saglabā masīvos.

## Funkcionalitāte
- Ievadīt studentu skaitu
- Ievadīt kritēriju skaitu
- Ievadīt studentu vārdus
- Ievadīt kritēriju nosaukumus
- Ievadīt katra kritērija svaru
- Ievadīt studenta atzīmes katram kritērijam
- Validācija:
  - vārdi drīkst saturēt tikai burtus
  - atzīmēm jābūt skaitļiem 0–10

## Mērķis
Programma izveidota, lai:
- novērstu kļūdas datu ievadē,
- iegūtu strukturētus studentu vērtēšanas datus,
- sagatavotu pamatu gala atzīmju aprēķiniem.

## Tehnoloģijas
- Java
- Scanner – lietotāja ievadei
- Regex – teksta validācijai
- Masīvi – datu glabāšanai
